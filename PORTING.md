# Porting and attribution

- Original project: [AutoTag](https://modrinth.com/mod/autotag)
- Original source: [apace100/autotag](https://github.com/apace100/autotag), branch `1.20`
- Original contributors: Apace and Will BL
- Original source license: MIT; the upstream `LICENSE` is retained
- Target: Minecraft 1.21.1, Fabric Loader 0.16.14 or newer, Java 21 or newer

This independent port retains both the AutoTag API and AutoTag Convention modules, the bundled API jar, the upstream tag definitions, the optional FabricShieldLib integration, and the upstream in-game mod icon. Source and compatibility changes are distributed under the retained MIT license. The port is not endorsed by the original authors.
